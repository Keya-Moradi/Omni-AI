I treat projects like I treat tabs on my desktop: only a few should be open at once. Everything else
waits in a queue.

## The pattern

1. Define a tight weekly scope. Ship that before adding more.
2. Keep a running changelog so context is never lost.
3. Automate once the steps repeat twice.

Keeping the workflow boring lets me focus on the work itself. The small rituals here make it easy to
show up every day without burning out.
